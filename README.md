# Currency Exchange Calculator

A simple currency exchange calculator built with plain HTML, CSS, and JavaScript.

## Features
- Convert between major world currencies
- Simple and responsive interface
- Uses live exchange rates when available
- Falls back to built-in rates if the API is unavailable

## Open the app
Open `index.html` in a browser, or serve the project locally with any static web server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — conversion logic and live rate fetching
