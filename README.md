# Currency Converter

**Live demo:** https://aditisonawane29.github.io/currency-exchange-calculator/

> Learning project: my first web tool using a live data API, built with GitHub Copilot.

A responsive currency exchange calculator built with plain HTML, CSS, and JavaScript. It fetches live rates when online and uses built-in fallback rates if the rate service is unavailable.

## Run locally
Open `index.html` in a browser, or start a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files
- `index.html` — app layout
- `style.css` — responsive styling
- `script.js` — conversion and rate-fetching logic

Rates are provided for convenience and may be delayed; do not use them as a financial quote.
